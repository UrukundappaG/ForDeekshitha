Q 1

Explain conditional branching with a flow chart or example. List and demonstrate one-way, two-way, and multiway branch with suitable examples.

Conditional branching allows a program to execute different blocks of code based on whether a specific condition evaluates to True or False.

One-way Branch (if): Executes a block only if the condition is true.

Python
x = 10
if x > 5:
    print("x is greater than 5")

Two-way Branch (if-else): Provides an alternative path when the condition is false.

Python
age = 16
if age >= 18:
    print("Eligible to vote.")
else:
    print("Not eligible to vote.")

Multiway Branch (if-elif-else): Checks multiple conditions in sequence until one matches.

Python
score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")

Q 7

Demonstrate entry-controlled loops and exit-controlled loops in Python with syntax and suitable examples.

Entry-Controlled Loop: The condition is checked before entering the loop body. If the condition is false initially, the body is never executed. Python's for and while loops are entry-controlled.

Python
count = 0
while count < 3:
    print(count)
    count += 1

Exit-Controlled Loop: The condition is checked after the body executes, ensuring it runs at least once. Python has no native do-while; it is emulated using while True with a break.

Python
# Emulating Exit-Controlled Loop
while True:
    password = input("Enter password: ")
    if password == "secret":
        break

Q 14

Explain the concept of recursive functions. Describe how recursion works with an example.

A recursive function calls itself directly or indirectly during execution. It breaks a large problem into smaller instances of the same problem. Every valid recursive setup requires:

  • Base Case: Tells the execution to stop.
  • Recursive Step: Continues the breakdown path toward the base case.

Trace of factorial(3):

  1. factorial(3) calls 3 × factorial(2)
  2. factorial(2) calls 2 × factorial(1)
  3. factorial(1) hits the base case and returns 1
  4. Values bubble back up: 2 × 1 = 2, then 3 × 2 = 6

Define String. Explain difference between 'abc', "abc" and """abc""".

A string is an immutable sequence of Unicode characters.

  • 'abc' — Single-quoted string. Useful for short, single-line expressions.
